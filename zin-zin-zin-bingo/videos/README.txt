Videos stored here are used instead of YouTube. Any video that isn't here still plays from YouTube.

Name each file after the instrument and which of its two videos it is:

  harp-1.mp4        harp-2.mp4
  piano-1.mp4       piano-2.mp4
  trombone-1.mp4    trombone-2.mp4
  violin-1.mp4      violin-2.mp4
  bassoon-1.mp4     bassoon-2.mp4
  drums-1.mp4       drums-2.mp4
  trumpet-1.mp4     trumpet-2.mp4     (trumpet-1 is also the demo video)
  guitar-1.mp4      guitar-2.mp4
  clarinet-1.mp4    clarinet-2.mp4
  flute-1.mp4       flute-2.mp4
  oboe-1.mp4        oboe-2.mp4
  french-horn-1.mp4 french-horn-2.mp4
  cello-1.mp4       cello-2.mp4

"1" and "2" follow the order of the YouTube videos in the game's settings
(the same order as the list on the first slide of the old deck).

Format: MP4 (H.264 video, AAC audio). 720p is plenty.
GitHub's web uploader takes files up to 25 MB each.
Don't use Git LFS - GitHub Pages won't serve those files.

After uploading, run "Check all videos" in the game's menu.
It reports how many videos are coming from GitHub and how many from YouTube.
